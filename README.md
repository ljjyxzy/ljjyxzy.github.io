# magicJJ

计算机学习笔记。

关于计算机底层原理与工程实践的学习心得，以及学习过程中的推导与复盘。

## 站点

- 线上地址：https://ljjyxzy.github.io/
- 纯静态站点，零依赖、零构建

## 结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 首页，文章列表 |
| `post.html` | 文章详情页，通过 `?id=N` 切换 |
| `archive.html` | 归档，按时间倒序，支持 `?tag=xxx` 标签筛选 |
| `about.html` | 关于 |
| `style.css` | 全部样式，设计 token 集中在 `:root` |
| `script.js` | 详情切换、标签筛选、入场动画 |

## 本地预览

直接用浏览器打开 `index.html` 即可，或用任意静态服务器：

```bash
python -m http.server 8000
```

## 更新流程

```bash
# 修改文件后
git add -A
git commit -m "post: 新增文章标题"
git push
```

推送后 GitHub Pages 会自动重新构建，约 1 分钟生效。

## 备注

文章编号采用十六进制区段分配：`0x` 后的第一位表示所属领域，第二位是该领域内的序号。

| 号段 | 领域 |
| --- | --- |
| `0x0_` | 计算机组成原理 |
| `0x1_` | 数据库 |
| `0x2_` | 算法 |
| `0x3_` | 操作系统 |
| `0x4_` | 编程开发 |
| `0x5_` | 生活随笔 |

`0x00` 保留给首页，不分配给文章。

新增文章时按内容所属领域取号，**不要按出现顺序顺排**。
